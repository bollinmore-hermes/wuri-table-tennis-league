# Issue #32 — 我關注的球隊

## 功能與邊界
- 在「球隊」頁打開某隊介紹，隊名旁有「關注此隊」按鈕；已關注時為「取消關注」，使用 `aria-pressed` 表達切換狀態。手機按鈕放在隊名下，不擠壓隊名。
- 一次關注一隊；在另一隊介紹頁按關注會取代原選擇。不需登入、不代表球員所屬隊伍。
- 首頁沒有選隊下拉選單或取消按鈕；只在已關注且資料有效時顯示摘要。未關注、資料未載入或球隊不再參賽時整個區塊隱藏，不自動刪除既有選擇。
- 使用球隊代碼及賽季隔離的 LocalStorage key `wuriLeagueFollow:<seasonCode>`，可更換、取消及跨同源分頁同步；不跨裝置同步。舊版已儲存選擇保持相容。
- 首頁摘要顯示目前公開資料的組內排名，以及臺灣時間尚未開始且尚無正式賽果的下一場比賽、時間與對手。
- 排名使用既有預設積分排序，不跟著戰績頁的欄位排序變化；不新增晉級規則或魔術數字。
- 現有公開資料契約未提供桌號，因此顯示「桌號待公布」。正式桌號資料接入屬 #24 的範圍，不推算桌號。
- 無後續賽程與儲存不可用有安全提示；儲存失敗仍可在目前分頁關注／取消，球隊介紹頁亦顯示無法保存的提示。
- 切換關注不重建球隊介紹頁的按鈕，保持滑鼠／鍵盤焦點；無資料庫、Auth、比分、帳號或任何伺服器端寫入。

## 使用者 Test 驗收
1. 打開固定 Test 網站，按「球隊」，再打開一支球隊的介紹頁。
2. 按隊名旁／下方的「關注此隊」，確認變為「取消關注」。
3. 回首頁，確認出現該隊摘要；重新整理後仍保留。
4. 到另一隊介紹頁按「關注此隊」，確認首頁改為新隊。
5. 回該隊介紹頁按「取消關注」，回首頁確認摘要消失；重新整理仍不顯示。
6. 手機查看介紹頁是否易讀，切換 EN／深色模式。

回覆格式：`#32 驗收通過`，或指出裝置／步驟／畫面問題。Test 驗收不等於正式站部署授權。
